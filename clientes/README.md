# Clientes

Cada cliente tem sua própria identidade: **as peças de cliente usam a marca do cliente**,
a Quirino aparece só como assinatura discreta (crédito "PRODUÇÃO quirino" ou vinheta final),
quando o cliente permitir.

| Pasta | Cliente | Tipo |
|---|---|---|
| `prefeitura-santanopolis/` | Prefeitura Municipal de Santanópolis | Órgão público (comunicação institucional) |
| `prefeito-vitor/` | Prefeito Vitor | Perfil pessoal / político |
| `deni-de-vitor/` | Deni de Vitor | Perfil pessoal |
| `itamar-supermercado/` | Itamar Supermercado | Comércio |

Em cada pasta:
- `brief.md` — quem é, cores, fontes, contatos, o que pode e não pode.
- `identidade/` — logo, brasão, fotos oficiais enviados pelo cliente (nunca recriar marca de cliente sem os arquivos originais).
- `entregas/AAAA-MM-DD-nome/` — cada vídeo, relatório ou card entregue.
