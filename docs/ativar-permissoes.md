# Ativar comandos sem aprovação (1 vez só)

O Claude não pode mudar as próprias permissões; precisa ser você.
Pelo celular, no GitHub:

1. Abra o repositório → **Add file → Create new file**.
2. Nome do arquivo: `.claude/settings.json`
3. Cole o conteúdo de `docs/settings-sugerido.json` e toque em **Commit changes** (no `main`).

Opcional: no modo **Auto** quase nada pede aprovação mesmo.
